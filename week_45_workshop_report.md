# Vending Machine Application

**Group 2 Team Members:** Ervin, Christopher, Soraya, Haleema, Ezhilarasi  
**Date:** 5 November 2026  

---

## Summary of Group Discussion

During our group workshop, we worked together on developing a Vending Machine Application. 

We started by discussing the requirements and sharing our ideas about how the vending machine should work. Everyone shared their thoughts and suggestions. Ervin shared the UML class diagram with the group, and we went through it together. We discussed the classes, methods, and how the different parts of the application should connect. 

### Task Distribution

After our discussion, we divided the work among the team members:
* **Haleema:** Subclasses and implementation
* **Soraya:** Abstract class
* **Ezhilarasi:** Interface
* **Ervin:** Exception handling
* **Christopher:** User Interface (UI)

### Git Workflow & Integration

Ervin created a GitHub repository and shared it with the group. We all cloned the repository into IntelliJ IDEA and created our own branches. Each of us worked separately on our assigned tasks. After finishing our code, we committed and pushed our changes to GitHub and created pull requests. Ervin reviewed and merged everyone's code into the main branch. 

In the afternoon, we worked together to connect all our code and run the application. We checked how the different parts worked together and discussed some issues that needed to be fixed. We made changes where needed and continued testing the application. We also completed the JUnit tests, and Ervin pushed the JUnit test code to the GitHub repository.
