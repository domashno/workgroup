## SUMMARY OF GROUP DISCUSSION 

During our group workshop, we worked together on planning and developing a Vending Machine Application. We started by spending approximately 50 minutes individually reading and understanding the assignment requirements. After that, we came together to discuss our understanding of the task, share ideas and decide how to design and implement the application. 

 During our group discussion, each member contributed ideas about the design and development of the Vending Machine application. For example, Ervin introduced the general idea of the Vending Machine application and discussed the requirement to create a runnable JAR file. Christopher suggested using an abstract class and subclasses and discussed the functionality that should be included in our code. Soraya also emphasized the importance of using an abstract class and subclasses to apply inheritance and polymorphism. Ezhil suggested creating a separate exception class to handle errors, making error handling more organized. Christopher also suggested dividing the tasks among group members so that everyone could contribute to the development. 

Initially, there was some confusion about how to divide the work. One suggestion was that a single member should create the entire project structure before the others started implementing the methods. However, Haleema suggested that each member should take responsibility for separate classes rather than dividing individual methods would be a better approach. After discussing this approach, we decided that each member would take responsibility for developing separate classes using the class diagram 

This approach allowed everyone to contribute to the coding and gave us an opportunity to practise the OOP concepts we had learned. 

Ervin shared the UML class diagram based on our discussions with the group, and we went through it together. We discussed the classes, methods, and how the different parts of the application should connect. 

After our discussion, we divided the work among the team members. Haleema worked on the subclasses and implementation class, Soraya worked on the abstract class, Ezhilarasi worked on the interface, Ervin worked on exception handling, and Christopher worked on the user interface (UI). 

Ervin created a GitHub repository and shared it with the group. We all cloned the repository into IntelliJ IDEA and created our own branches. Each of us worked separately on our assigned tasks. After finishing our code, we committed and pushed our changes to GitHub and created pull requests. Ervin reviewed and merged everyone's code into the main branch.   

In the afternoon, we worked together to connect all our code and run the application. We checked how the different parts worked together and discussed some issues that needed to be fixed. We made changes where needed and continued testing the application. 

We also created the JAR file for our Vending Machine application. To build and run the application, we used the command `mvn clean package && java -jar target/lexicon-vending-machine-1.0-SNAPSHOT.jar` in the terminal. This command builds the JAR file and runs the application. 

We also completed the JUnit tests, and Ervin pushed the JUnit test code to the GitHub repository.
